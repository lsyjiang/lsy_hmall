## cart-service 启动失败修复（20:15）

- 现象：启动抛 `NoClassDefFoundError: io/r2dbc/spi/ValidationDepth`，`Could not evaluate condition on ConnectionFactoryConfigurations$PoolConfiguration`。
- **根因：所有类都在默认包**（`CartApplication` 无 package，`controller`/`domain.po`/`mapper`/`service` 都是顶级包）。`@SpringBootApplication` 的组件扫描根变成默认包 → 扫描整个 classpath，读到 spring-boot-autoconfigure 的 r2dbc 类就炸。日志里的关键提示：`Your ApplicationContext is unlikely to start due to a @ComponentScan of the default package.`
- 附带问题：`@MapperScan("com.hmall.cart.mapper")` 指向不存在的包；VM 上没有 `hm-cart` 库。
- 已做：全部源码重构到 `com.hmall.cart.{controller,domain.dto,domain.po,domain.vo,mapper,service,service.impl}`；`mvn clean compile` 通过；上传并导入 `F:\BaiduNetdiskDownload\hm-cart.sql`（建库 hm-cart + cart 表）；启动后 `GET /carts` 返回 200 和真实数据（id=7 的购物车条目）。
- 注意：cart-service 同样用了 `lambdaQuery`，IDEA 运行配置必须带 `--add-opens java.base/java.lang.invoke=ALL-UNNAMED`。
- VM 现有库：`hmall`、`hm-item`、`hm-cart`、`tlias`。
